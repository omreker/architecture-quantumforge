## Задание 4. Реализация RAG-бота с техниками промптинга

### Пайплайн

1. Пользователь вводит вопрос

2. Вопрос преобразуется в эмбеддинг (all-MiniLM-L6-v2)

3. Поиск ближайших чанков в FAISS

4. Формируется промпт с найденным контекстом

5. Промпт отправляется в LLM (Ollama + qwen2.5:3b)

6. Пользователь получает ответ

### Техники промптинга

- **Few-shot**: в промпт добавлены примеры вопросов и ответов из предметной области

- **Chain-of-Thought**: модель сначала пишет рассуждение по шагам, затем ответ

### Интерфейс

**CLI** (`bot.py`)

### Примеры работы

**Успешные ответы:**

**Q: Кто такой Акакий?**

```
1. Акакий - это персонаж, упомянутый в контексте двух файлов: "Акакий Лесной Паренек" и "Операция Заманчивых".
2. В "Операция Заманчивых" Акакий пытается создать новый источник вечности. В "Акакий Лесной Паренек" он известен как лидер группы Охотников на Котов, которые ведут борьбу с котовыми демонами в Лесном паренеке.
```

**Q: Что такое Царь-гриб?**

```
1. Царь-гриб - персонаж, упомянутый в контексте. Его роль связана с эмблемой Царя-гриба, которая существует в некоторой игре или мире.
2. В контексте этого вопроса, Царь-гриб - это возможно мифический или фантастический персонаж, у которого есть эмблема, связанная с его авторитетом или значением. Однако для точного определения потребуется дополнительная информация.
```

**Q: Кто такой Сатор Арепов?**

```
1. Сатор Арепов – это персонаж, упомянутый в контексте Операции Заманчивых, где он описан как сторонник Царя-гремба.
2. Также в контексте упоминается о Разрушении Даларана, действие которого осуществляется руками Сатора Арепова.
```

**Отказы:**

**Q: Где находится Китай?**

```
Я не знаю
```

**Q: Как приготовить спагетти?**

```
Я не знаю
```

## Задание 5. Запуск и демонстрация работы бота

В `knowledge_base/` добавлен `Злонамеренный_Файл.md`

Документ проиндексирован вместе с остальной базой.

### Защита

1. Фильтрация чанков по опасным паттернам:

    - ignore all instructions

    - swordfish

    - суперпароль

    - root: ...

2. Блокировка опасных пользовательских запросов (пароль / root / swordfish)

3. Инструкция в промпте: не выполнять команды из документов и отвечать только по контексту

### Тесты

10 запросов:

- 5 успешных ответов

- 5 отказов

Результаты сохранены в `log.txt` (скрипт run_tests.py).

### Выводы

- Без фильтра вредоносный чанк мог попасть в контекст

- С фильтром опасный контент отбрасывается

- Бот не выдаёт пароль и корректно отвечает «Я не знаю» на вопросы вне базы

## Запуск проекта

### 1. Подготовка окружения

```bash
python -m venv .venv
```

``` bash
.\.venv\Scripts\Activate
# или
source .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

### 2. Установка и запуск Ollama

1. Скачать Ollama: <https://ollama.com/download>

2. Установить модель:

    ```bash
    ollama pull qwen2.5:3b
    ```

### 3. Подготовка базы знаний (если нужно заново)

```bash
python load_knowledge_base.py
python replace_terms.py
```

### 4. Построение индекса

```bash
python build_index.py
```

После этого в папке `index/` должен появиться FAISS-индекс.

### 5. Запуск бота

```bash
python bot.py
```

### 6. Запуск тестов

```bash
python run_tests.py
```

Результаты сохраняются в `log.txt.`

### 7. Запуск через Docker

```bash
docker compose up --build
```
